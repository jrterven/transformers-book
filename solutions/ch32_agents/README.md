# Chapter 32. AI Agents with Language Models

All [13 exercises](../../examples/ch32_agents/EXERCISES.md) have worked
solutions in the same order as the book.

- [Written solutions](written-solutions.pdf) with explanations, calculations, and trace tables.
- [Executed Jupyter notebook](python-solutions.ipynb) with the worked solutions and 12 executed Python cells.
- [Notebook PDF](python-solutions.pdf) with the explanations, code, and outputs.

The checks cover remaining tool budgets, schema validation, exact group
prices, clarification, and recovery after a simulated wait. The notebook reads
the [recorded runs](../../examples/ch32_agents/records/) of the local model and
uses the chapter's Python tools. The timeout exercise uses an in-memory
reservation fixture.

## Run the notebook

Use Python 3.10 or later with the repository's files available locally.
Open the notebook in Jupyter and run all cells in order from the repository
root or the notebook's folder. The cells use the Python standard library
and the saved records.

```sh
python -m pip install jupyterlab
jupyter lab
```

See the [chapter guide](../../examples/ch32_agents/) to repeat the model
runs that produced the saved traces.
